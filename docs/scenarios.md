# 业务演练

|情景|查询约束|覆盖结论|
|---|---|---|
|截断|默认 cap=3|200 不算完整，按空间或时间进一步规划|
|边界点|坐标 0、2、4 以及时间边界|分界包含规则不漏点，重复点只入账一次|
|足够容量|cap=30|可在有限请求内证明完整，全域共 23 条唯一记录|
|密集热点|默认 cap 且五条同空间时间|到最小粒度仍截断应明确热点未完成|
|预算不足|限制实际请求次数|requestsUsed 不越限，待办树可以恢复|
|中断|叶子完成后退出|重启不重查已经完成且仍属有效快照的叶子|
|快照过期|generation=2|旧代结果不能与新代拼接成完整声明|
|证明篡误|任一截断叶子标 complete|校验或测试必须拒绝|
